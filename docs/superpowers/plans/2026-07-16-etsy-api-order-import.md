# Etsy API Order Import Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a secure, operator-initiated Etsy Open API v3 import to the Orders workspace with OAuth connection management, idempotent paid/unshipped order ingestion, and accessible streamed progress.

**Architecture:** Keep Etsy integration code outside the general Orders route. Focused server modules own encrypted workspace connections, OAuth, Etsy HTTP requests, normalization, and import orchestration; three API routes expose connection state, the OAuth callback, and a newline-delimited import stream. The browser uses a small Etsy API client and passes normalized items into the existing Orders persistence path on the server.

**Tech Stack:** Node.js ES modules, Vercel-style API handlers, Etsy Open API v3, OAuth 2.0 Authorization Code + PKCE, Node `crypto` AES-256-GCM, Supabase Postgres, vanilla browser JavaScript/CSS, Vitest, Playwright.
