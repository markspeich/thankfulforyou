# Editable Built-In Fonts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Allow Candlepin, Skywalk, and Somekind to receive uploaded new versions from the Fonts workspace while preserving their stable font ids.

**Architecture:** Keep the hard-coded built-in font definitions as local fallbacks, but allow Supabase font rows with the same ids to override those definitions. Treat `is_builtin` as origin metadata instead of a mutation lock for replacement, while keeping deletion guarded for the original production font ids. Seed built-in font rows for the primary workspace so local and deployed databases have editable records.

**Tech Stack:** Vanilla ES modules, Vitest, Playwright, Supabase Postgres/Storage, Vercel-style API routes.
